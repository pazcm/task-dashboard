# Task Dashboard app
_An accesible and responsive tasks dashboard_ <br>

> Built with **React** + **TypeScript** + **ESLint** + **Vite**


Features
---
- View a list of tasks
- Filter and search tasks
- Create a task
- Edit/delete a task
- Mark tasks as completed
- View task details
- Navigate between sections
- Handle loading, empty and error states
- Use the application entirely with a keyboard
- Responsive<br>

Development workflow (dev > stage > main)
---
1. Create new __Feature branches__ from `stage`
2. Merge __Feature branches__ into `dev` for early testing
3. Once tested, merge __Feature branches__ into `stage` for final testing
4. After passing testing, `stage` is merged into `main`
5. Finally, `stage` is synced back to `dev` to maintain consistency
